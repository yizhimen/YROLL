# 去停顿（口播节奏收紧）

## 什么时候做
- 用户说"停顿太多/节奏慢/太啰嗦/把空白剪掉/去气口"
- 口播、访谈、课程类素材，说话人中间有明显沉默

## 怎么判断
- 只对**有人声的主 clip** 做；BGM、纯画面 clip 不要做
- 转写文本里句子之间的大间隔 = 停顿候选
- 阈值经验：noise_db=-35 适合室内口播；户外/嘈杂素材放宽到 -30

## 注意什么
- 句尾气口不要切太狠——silence_remove 已带 padding 保护尾音，不要再额外 trim
- 去停顿后 clip 会被重建为多段，后续的 trim/volume 要基于新 clip_id（看执行结果）
- 删除类风险：本操作是重建而非删除素材，源素材不变，可放心执行
